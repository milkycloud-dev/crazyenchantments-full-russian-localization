## English

### Overview

This repository provides clean, standalone Russian localization files for **CrazyEnchantments v26.3-b3d45a2 (BadBones69 / RyderBelserion)**.
It contains only configuration and text files to respect original author licensing and copyright requirements.

### Files

- `Messages.yml`: All 67 message keys translated (commands, errors, limits, migration).
- `Enchantments.yml`: All 105 custom enchantments with Russian names, types, and clear descriptions.
- `Tinker.yml`: Tinkerer trading interface localized.
- `GKitz.yml`: GKitz GUI and inventory header localized.
- `Enchantment-Types.yml`: Enchantment info GUI and navigation buttons localized.
- `config.yml`: Crazy shop categories and titles localized.

### Installation

1. Stop your Minecraft server.
2. Copy configuration files into `plugins/CrazyEnchantments/`.
3. Start the server or run `/ce reload`.

## Русский

### Описание

Репозиторий содержит чистые файлы русской локализации для **CrazyEnchantments v26.3-b3d45a2 (BadBones69 / RyderBelserion)**.
В состав включены исключительно файлы конфигурации и переводов, без бинарных сборок, с соблюдением требований лицензий авторов.

### Файлы

- `Messages.yml`: Все 67 категорий сообщений переведены (команды, ошибки, лимиты, миграции).
- `Enchantments.yml`: Все 105 кастомных чар с русскими названиями, типами предметов и понятными описаниями.
- `Tinker.yml`: Интерфейс обмена у Сборщика (Tinkerer).
- `GKitz.yml`: Меню и заголовок инвентаря G-наборов.
- `Enchantment-Types.yml`: Меню информации о типах чар и кнопки навигации.
- `config.yml`: Категории магазина и заголовки интерфейсов.

### Установка

1. Остановите сервер Minecraft.
2. Скопируйте файлы конфигурации в папку `plugins/CrazyEnchantments/`.
3. Запустите сервер или выполните команду `/ce reload`.
