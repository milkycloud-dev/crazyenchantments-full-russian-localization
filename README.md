## English

### Overview

This repository provides clean, standalone Russian localization files for **CrazyEnchantments v26.3-b3d45a2 (RyderBelserion)**.
It contains only configuration and text files to respect original author licensing and copyright requirements.

### Files

- `Messages.yml`: All 67 message keys translated.
- `Enchantments.yml`: All 105 custom enchantments translated.
- `Tinker.yml`, `GKitz.yml`, `Enchantment-Types.yml`, `config.yml`.

### Installation

1. Copy configuration files into `plugins/CrazyEnchantments/`.
2. Or download the pre-built `.jar` from [Releases](https://github.com/milkycloud-dev/crazyenchantments-full-russian-localization/releases/latest).

### Releases

Pre-built ready-to-use binaries (`.jar` / `.zip`) are available for download in [Releases](https://github.com/milkycloud-dev/crazyenchantments-full-russian-localization/releases/latest).

## Русский

### Описание

Репозиторий содержит чистые файлы русской локализации для **CrazyEnchantments v26.3-b3d45a2 (RyderBelserion)**.
В состав включены исключительно файлы конфигурации и переводов, без бинарных сборок, с соблюдением требований лицензий авторов.

### Файлы

- `Messages.yml`: Все 67 категорий сообщений переведены.
- `Enchantments.yml`: Все 105 кастомных чар с понятными описаниями.
- `Tinker.yml`, `GKitz.yml`, `Enchantment-Types.yml`, `config.yml`.

### Установка

1. Скопируйте файлы конфигурации в папку `plugins/CrazyEnchantments/`.
2. Либо скачайте готовую сборку `.jar` из раздела [Releases](https://github.com/milkycloud-dev/crazyenchantments-full-russian-localization/releases/latest).

### Релизы

Готовые собранные бинарные пакеты (`.jar` / `.zip`) доступны для загрузки в разделе [Releases](https://github.com/milkycloud-dev/crazyenchantments-full-russian-localization/releases/latest).
